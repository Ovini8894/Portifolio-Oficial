# 💼 Site Portfólio Pessoal

Este projeto consiste no desenvolvimento de um **site portfólio pessoal**, com o objetivo de apresentar informações profissionais, projetos desenvolvidos e facilitar o contato com visitantes e recrutadores.

O site foi desenvolvido utilizando **HTML, CSS e JavaScript**, com foco em um layout moderno, responsivo e funcional, incluindo um **botão de contato que redireciona para o WhatsApp** a partir de um formulário simples.

---

## 🎯 Objetivo do Projeto
- Criar um portfólio online para apresentação profissional  
- Exibir projetos e habilidades técnicas  
- Facilitar o contato direto via WhatsApp  
- Praticar conceitos de desenvolvimento front-end  

---

## 🛠️ Tecnologias Utilizadas
- **HTML5** – Estruturação do conteúdo  
- **CSS3** – Estilização, layout e responsividade  
- **JavaScript** – Interações e lógica do formulário  

---

## 📄 Funcionalidades
- Página inicial com apresentação pessoal  
- Seção de projetos desenvolvidos  
- Seção de habilidades técnicas  
- Formulário de contato simples  
- Botão que redireciona para o WhatsApp com os dados do formulário  
- Layout responsivo para diferentes dispositivos  

---

## 📱 Integração com WhatsApp
O formulário coleta informações básicas do usuário e, ao ser enviado, o botão de contato **redireciona automaticamente para o WhatsApp**, enviando uma mensagem pré-formatada, facilitando a comunicação direta.

---

## 🚀 Aprendizados
Com este projeto, foi possível:
- Estruturar um site completo utilizando HTML  
- Aplicar estilização responsiva com CSS  
- Utilizar JavaScript para manipulação de formulário e redirecionamento  
- Entender a importância da experiência do usuário em sites pessoais  

---
